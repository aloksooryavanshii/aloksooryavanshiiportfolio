# Alok Kumar — Content Writer Portfolio

A modern, fully responsive portfolio website for content writers.

## Files
```
index.html   ← Main HTML structure
style.css    ← All styles (light/dark mode, responsive)
script.js    ← Interactions, animations, form validation
```

## Deploy to GitHub Pages

1. Create a new GitHub repository (e.g., `portfolio`)
2. Upload all 3 files to the root of the repository
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)`
5. Click **Save** — your site will be live at:
   `https://yourusername.github.io/portfolio/`
